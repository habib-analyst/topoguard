# TopoGuard

**Topology-adaptive Byzantine defense for decentralized federated learning.**

Fixed robust-aggregation rules (Krum, trimmed mean, geometric median,
BALANCE) are tuned as if the communication graph didn't matter — but the
*effective* Byzantine fraction inside a node's neighborhood is a function
of the graph. The same 20% Byzantine rate that Krum survives on a dense
graph destroys it on a sparse ring. TopoGuard adapts **how each node
aggregates** to its local topology, every round.

## The idea in 30 seconds

Each node, each round:

1. **Trust** — scores every neighbor by how *typical* its update is
   (EWMA over rounds).
2. **Topology** — measures its own neighborhood evidence uncertainty
   `φ = 1/√degree`. Few neighbors → you can't tell friend from foe.
3. **Exposure** — `e = (1 − mean trust) + c·φ`: observed hostility plus
   topological uncertainty.
4. **Select** — picks an aggregation rule from a portfolio by exposure:
   trust-weighted mean → trimmed mean → BALANCE-style accept (with a
   *topology-conditioned* threshold) → geometric median.

Dense graph + honest neighbors → light touch (FedAvg-like utility).
Sparse ring or active attack → conservative rules + up-weighted own
update. The same attack is handled differently on a ring vs. a clique —
because it should be.

## Measured results (1,890-cell matrix, `eval/main.jsonl`)

Mean final honest-node accuracy over 3 topologies × 5 attacks × 3
Byzantine fractions × IID/non-IID × 3 seeds (N=10, 15 rounds):

| defense | mean acc |
|---|---|
| geometric median | 0.9656 |
| **TopoGuard trust-only** (selection fixed at L0) | **0.9626** |
| BALANCE-fixed | 0.9375 |
| Krum | 0.9368 |
| TopoGuard fused (per-round selection) | 0.9214 |
| trimmed mean | 0.8403 |
| FedAvg | 0.7002 |

**Honest headline:** the fused flagship's per-round rule selection
*fails* its falsification test against the trust-only variant — it loses
on 13/15 topology×attack cells and collapses to 0.31–0.32 on sign_flip at
30% Byzantine (star/complete), where it escalates to the trimmed-mean
portfolio entry whose β=0.2 breakdown point the 30% fraction exceeds,
re-admitting excluded neighbors (the hard-exclusion mask binds only at
levels 0/2). Trust estimation + hard exclusion is the load-bearing
component (removing trust collapses sign_flip to 0.27); **ship the
trust-only variant**. Full story in `PAPER.md` §4–§6, including the
mechanism-level failure analysis — the negative result is the result.

## Use it in your DFL loop

```python
from topoguard import TopoGuard

# one stateful aggregator per node (keeps per-neighbor trust)
# measured recommendation: trust-only variant (select=False, fixed_level=0)
# — per-round selection fails falsification (see PAPER.md §4.2)
agg = TopoGuard(
    select=False, fixed_level=0,   # trust-only: the shipped defense
    c=0.25, kappa=1.0, tau=(0.2, 0.45, 0.9),  # measured hyperparams
)

# each round, at node i:
new_model_flat, report = agg.aggregate(
    own=own_update_flat,            # torch.Tensor
    neighbors={j: update_flat_j},   # dict[node_id, torch.Tensor]
)
print(report)  # {'level': 0, 'exposure': 0.31, 'phi': 0.33, ...}
```

See `examples/` for a complete decentralized training loop.

## Reproduce the paper

```bash
# pilot: mechanism selection (trust-only vs selection-only vs fused)
python -m topoguard.eval --phase pilot --out eval/pilot.jsonl --resume
# full matrix: topology x defense x attack x fraction (resumable shards)
python -m topoguard.eval --phase main --shard 0 --nshards 2 --out eval/main.jsonl --resume
python -m topoguard.eval --phase main --shard 1 --nshards 2 --out eval/main.jsonl --resume
# held-out family (random_geometric, never tuned on), ablations, time-varying
python -m topoguard.eval --phase heldout  --out eval/heldout.jsonl  --resume
python -m topoguard.eval --phase ablation --out eval/ablation.jsonl --resume
python -m topoguard.eval --phase timevary --out eval/timevary.jsonl --resume
# rebuild every paper table from measured records (no hand-typed numbers)
python scripts/summarize.py
```

Launch shards detached (`setsid nohup ... &`); `--resume` skips finished
cells after daemon restarts.
